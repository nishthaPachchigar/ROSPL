🧩 Modules

One engine, 9 MCP tools — all modules available on both the web dashboard and the MCP server.

🔎 Recon Module

Subdomain enumeration + live-host resolution using free Certificate Transparency logs (HackerTarget / crt.sh) with DNS brute-force fallback.

server/recon.py

🚪 Port Scanner

Concurrent TCP scan of 21 common ports (SSH/HTTP/MySQL/Redis/RDP…) per host, dangerously-exposed ports flagged red.

server/ports.py

📍 GeoIP + WHOIS

ip-api.com batch GeoIP (country/city/ISP per IP) + IANA RDAP domain registration/holder/expiry.

server/geoip.py

🚨 CVE Module

OSV vulnerability database + EPSS exploitation probability + CISA Known Exploited Vulnerabilities.

server/cve_intel.py

📋 Inventory Scan

Auto-detects software from requirements.txt / package.json / go.mod / Cargo.toml / composer.json → maps each to OSV CVEs (supply-chain view).

server/inventory.py

🔑 Secrets Module

20+ regex patterns (AWS, GitHub, Discord, Telegram, OpenAI, Groq…) — working tree + full git history scan.

server/leaks.py

📄 Report Module

Markdown (readable) + SARIF (CI/GitHub code-scanning standard) + print-ready PDF report generation.

server/report.py

🤖 MCP Server

The same engine exposed as an MCP (Model Context Protocol) server — 9 tools for any AI client. AI ka 'USB port'.

server/main.py

⚡ Orchestration

'Full Audit' chains recon → ports → geoip/whois → vulns → secrets → report (MD/SARIF/PDF) in one call.

webapp/app.py
